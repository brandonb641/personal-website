
# My Personal Website

## Name
Brandon

## Website Description
This is my personal website created to introduce myself, share my interests and goals, display my skills and courses, and provide contact information.

## Redesign Summary
The website was redesigned using semantic HTML5 elements and responsive CSS. The navigation was updated, images were organized into folders, and an externally hosted image was added to the portfolio page. Comments were added to make the code easier to understand.

## Technologies Used
- HTML5
- CSS3
- Git and GitHub
- Visual Studio Code

```text

```

## How to View the Website
Open `index.html` in a web browser. Navigate between the Home, About, Portfolio, and Contact pages using the navigation menu.

## Responsive Design
CSS Flexbox and media queries are used to adapt the navigation, text, images, and table to desktop, tablet, and mobile screen sizes.

## Image Credits
- Profile photo: Locally stored image in the `images` directory.

## Reflection

During this redesign, I learned how to organize a website using separate folders for CSS and images. I also learned how semantic HTML elements such as header, nav, main, section, and footer improve the structure and readability of a webpage. Adding comments helped me understand how to make my code easier for other developers to follow.

One challenge was moving the CSS file and profile image into new folders without breaking the links in my HTML pages. I solved this by updating the file paths. I also learned how to use CSS media queries to make a website more responsive on mobile phones, tablets, and desktop computers.

Working with Git branches helped me understand how to make changes separately from the main version of a project. I also learned that meaningful commits help track progress and that a Pull Request allows changes to be reviewed before merging them into the main branch. Overall this project improved my confidence in HTML, CSS, responsive design, and version control.
