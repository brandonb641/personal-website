# My Personal Website

## Name
Brandon

## Website Description
This is my personal website created to introduce myself, share my interests and goals, display my skills and courses, and provide contact information.

The website was enhanced using JavaScript to introduce interactive features that improve the visitor's experience.

## JavaScript Features

Five JavaScript features were implemented:

1. **Dark/Light Mode Toggle:** Allows visitors to switch between dark and light website themes.
2. **Digital Clock:** Displays the current time and updates every second.
3. **Character Counter:** Counts the number of characters entered into the contact message box, with a limit of 300 characters.
4. **Back-to-Top Button:** Appears when visitors scroll down and allows them to return smoothly to the top of the page.
5. **Time-Based Welcome Message:** Displays a greeting based on the visitor's current time of day.

## Reflection

During this assignment, I learned how JavaScript can make a website more interactive and improve the user experience. I implemented five features, including a dark and light mode toggle, a digital clock, a character counter, a back-to-top button, and a time-based welcome message. These features helped me understand how JavaScript works with HTML elements.

One challenge I experienced was connecting the external JavaScript file to all four HTML pages and making sure the features worked correctly. I also had to troubleshoot issues with the CSS styling and navigation links. Through this process, I learned how to use event listeners, variables, functions, and DOM manipulation to create and update webpage elements.

I also gained more experience using Git and GitHub. Creating a separate branch allowed me to work on the JavaScript enhancements without directly changing the main branch. I learned how meaningful commits and Pull Requests help organize, review, and merge project changes. Overall, this assignment improved my understanding of JavaScript, DOM manipulation, debugging, and version control.
